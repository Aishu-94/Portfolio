# Aishwarya V. V. — Portfolio Website

A responsive dark-theme portfolio built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — website content
- `style.css` — layout, colours, responsive styles, animations
- `script.js` — mobile menu, scroll reveals, active navigation, back-to-top button
- `images/profile.jpg` — profile photo

## Run locally
1. Extract the ZIP file.
2. Open the `AishwaryaPortfolio` folder in Visual Studio Code.
3. Install the **Live Server** extension if it is not already installed.
4. Right-click `index.html` and choose **Open with Live Server**.

You can also open `index.html` directly in a browser.
